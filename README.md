# Portfolio — Amine Elkarmi

Portfolio statique bilingue français/anglais, compatible GitHub Pages.

- Ouvrir `index.html` ou servir le dossier avec `python -m http.server 8765`.
- 14 projets documentés, filtrables par IA/données ou génie logiciel.
- CV : `cv-amine-elkarmi-fr.pdf` et `cv-amine-elkarmi-en.pdf`.
- Le profil de ces deux CV mentionne le projet de poursuivre un doctorat en IA.
- Les dépôts privés peuvent demander une authentification GitHub.
- Le formulaire prépare un email dans l’application de messagerie du visiteur ; il ne transmet rien à un serveur.
- Les polices, icônes et le fond Three.js utilisent des CDN ; le contenu et les téléchargements sont locaux.

Les descriptions présentent le périmètre documenté des dépôts, sans métriques inventées ni attribution de tout le travail d’équipe à une seule personne. Les projets RoadHelp_Maroc et S_AA restent exclus à la demande du propriétaire.
